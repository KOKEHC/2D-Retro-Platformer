2D Retro Platformer Controller & Mechanics

Полнофункциональный прототип классического 2D-платформера на Unity. Проект сфокусирован на отзывчивом управлении персонажем, модульном искусственном интеллекте врагов и поддержке как ПК, так и мобильных устройств.



 ⚙️ Стек технологий
 **Unity:** 2023 / Unity 6 (использован современный Rigidbody2D.linearVelocity)
 **Язык:** C#
 **Ввод:** Unity New Input System + кастомная сенсорная система ввода для тачскринов (UI Event Systems)
 **Рендеринг:** 2D Sprite Renderer, система частиц (Particle Systems) для спецэффектов

---

 🕹️ Реализованные механики

 1. Продвинутый контроллер персонажа (PlayerController.cs)
 **Физика перемещения:** Плавный бег, настраиваемая гравитация и прыжки.
 **Взаимодействие со стенами (Wall Mechanics):** Скольжение по стене (Wall Slide) и отталкивание от стены (Wall Jump) с защитой от спама на одной стене.
 **Лестницы:** Полная механика карабканья с отключением гравитации.
 **Боевая система (Damage System):** 
   Отскок (Knockback) от источника урона.
   Кадры неуязвимости (i-frames) с эффектом мерцания спрайта.
   Прыжок на врага сверху (Mario-style bounce).

 2. Модульный AI врагов (EnemyController.cs)
 **Патрулирование (GroundPatrol):** Проверка обрывов и препятствий с помощью Raycast2D.
 **Зрение и преследование:** ИИ видит игрока через Line-of-Sight (луч не должен блокироваться стенами) и преследует его. Потеря агро придистанции или уходе из поля видимости.
 **Летающие враги (FlyingWaypoints):** Движение по узловым точкам (Waypoints) с автоматическим разворотом спрайта.

 3. Интерактивное окружение и физика
 **Движущиеся платформы (MovingPlatform.cs):** Плавное перемещение с привязкой игрока через иерархию (SetParent).
 **Падающие платформы (FallingPlatform.cs):** Таймер разрушения при наступании сверху с переключением типа Rigidbody2D в Dynamic.
 **Бесконечный фон (InfiniteBackground.cs):** Эффект параллакса (Parallax 2D) по оси X и адаптация к вертикальной камере.
 **Плавная камера (CameraFollow.cs):** Следование за игроком с использованием Vector3.SmoothDamp.

 4. Кроссплатформенное управление (Mobile Ready)
 Кастомный экранный джойстик (VirtualJoystick.cs) на интерфейсах IDragHandler, IPointerDownHandler.
 Экранные кнопки прыжка без задержки кадра ввода.


 ⌨️ Управление
 **A / D** или **Стрелочки** — Движение
 **W / S** — Вверх/Вниз по лестницам
 **Пробел** — Прыжок / Прыжок от стены
 *На мобильных устройствах доступен экранный Virtual Joystick и кнопка Jump.*
